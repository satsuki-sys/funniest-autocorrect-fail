A make.fun bounty entry for the **Funniest Autocorrect Fail** competition.

## What it does

`main.py` writes one line — a funny autocorrect fail — to `/output/entry.txt`:

> Babe, I left your penis pasta in the fridge, heat it up for 2 minutes

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
